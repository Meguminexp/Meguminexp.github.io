# 星尘守卫 · 爱心小角落塔防 (v3)

一个**像素风元素肉鸽塔防**游戏：5 大元素流派、章节推进、每波三选一构筑、开局遗物、随机事件、星尘局外养成。零依赖、单页可玩、`file://` 双击即开。

> 完整的系统与数值设计见 **[DESIGN.md](DESIGN.md)**；平衡性由 `test/sim.js` 无头 AI 模拟全章节验证。

## 运行

```bash
# 方式一: 直接双击 index.html（零依赖, file:// 可跑）
# 方式二:
cd td-game
python3 -m http.server 8000     # 打开 http://localhost:8000
```

## 核心玩法

- **章节推进**：5 章 × 10 波（第 5/10 波 Boss）。通关解锁下一章 + 对应元素塔；已通关章节可重玩刷星尘
- **元素克制与反应**：`火→木 · 冰→火 · 雷→水 · 木→雷` 克制 ×1.5（可被「弱点猎手/猎杀印记」提升）；反应：**燃爆**(火+木)、**破甲**(冰+雷)、**蒸发**(冰+火)、**导电**(雷+水)
- **开局遗物**：每局开始三选一（8 种遗物：存钱罐/双生卷轴/猎杀印记/幸运星/荆棘之心/时间沙漏/饕餮之口/学者之眼），决定本局流派
- **肉鸽三选一**：每波清空后 3 选 1（学者之眼开局 4 选 1），含全局池 18 张 + 本章元素专属池 25 张（主题牌权重 ×3）+ 危险牌（副作用换高收益）
- **随机事件**（10 种）：熔岩爆发/暴风雪/雷暴/酸雨/宝藏波/精英波 + 新增 双倍波次/黄金雨/暗影契约/回春
- **建塔/升级/出售**：塔 3 级成长（伤害×1.5/1.35），点击塔弹出详细面板（含期望 DPS 与升级预览），右键快捷出售
- **17 种敌人 + 5 章 Boss**：新增 剧毒花妖/冰晶蝠/装甲蟹/治疗祭司/爆破傀儡；Boss 半血狂暴；精英词缀 6 种（迅捷/吸血/分裂/护盾/狂暴/荆棘）
- **星尘商店**：星尘解锁元素塔/章节/难度/开局祝福；设置/图鉴/教程齐全

## 元素塔 · 五大门派

| 塔 | 流派 | 核心机制 |
|---|---|---|
| ⭐ 星塔 | 精准爆击流 | 25% 暴击×3.0，金色暴击大字，堆暴击率/倍率 |
| 🌋 火塔 | 点燃蔓延流 | 灼烧可叠加，被灼烧敌人死亡爆炸传染，火系免疫岩浆 |
| ❄️ 冰塔 | 冻结碎裂流 | 冻结目标被命中冰裂溅射+易伤，冰面冻结率×2 |
| ⚡ 雷塔 | 电弧过载流 | 连锁弹跳+电涌区域，概率过载全屏电弧，雷石+20% |
| 🌿 木塔 | 剧毒纠缠流 | 毒雾缠绕减速，中毒死亡留毒池，毒沼范围+50% |

## 平衡与验证

`node test/sim.js` 用 jsdom + 假 canvas 加载真实游戏脚本，AI 玩家（相位布防/主题优先/经济加权选牌）全章节自动游玩。v3 实测 120 局：

- **甜梦**：全章 100% 胜（新手必胜）
- **心动**：全章 100%（舒适挑战）
- **心颤**：ch1 38%（单塔流开荒墙）/ ch2-5 100%（极限压力点：精英墙+Boss 墙+退款减半）

详细数值模型（DPS 预算、经济曲线、成长公式、星尘定价）见 DESIGN.md。
