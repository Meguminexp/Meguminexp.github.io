# 星尘守卫 · 肉鸽塔防 完整设计文档 (v3)

> 本文档是 `index.html` 重制版的唯一设计依据：**所有数值、系统、UI 均以本文档为准**，代码逐条落实。
> 目标：把现有可玩原型升级为一款**数值可验证、肉鸽循环完整、UI 精致**的像素风元素塔防肉鸽。

---

## 1. 设计目标与理念

- **一句话**：以「5 大元素 × 5 大流派」为核心，章节推进解锁 + 每波三选一肉鸽构筑 + 星尘局外养成。
- **三个支柱**：
  1. **流派可辨识**：每座塔不是属性差异，而是完全不同的"打法风格"（暴击 / 点燃 / 冻结 / 连锁 / 毒雾），鼓励围绕流派组 build。
  2. **选择有意义**：三选一里出现"强化本流派 / 补短板 / 冒险换收益"三类牌；元素反应、克制、地形互相咬合。
  3. **数值可验证**：所有成长曲线由公式驱动，并用自动化模拟（`test/sim.js`）全章节试玩验证——普通难度"合理操作必胜、手滑会漏怪"，噩梦难度"极限挑战"。
- **技术约束**：零外部依赖、`file://` 双击可玩、60fps 固定步长、`localStorage` 存档（v3 版本化 + v2 迁移）。

## 2. 核心循环

```
世界地图选章节/难度
   → 开局：遗物三选一（肉鸽风味）
   → BUILD 布防（任意时刻可随时开波）
   → WAVE 战斗（随机事件可能触发）
   → 波次清空 → DRAFT 三选一（含波次奖励）
   → BUILD …
   → 第 10 波章节 Boss → 胜利结算（星尘奖励） / 基地血量归零失败
   → 星尘商店：解锁塔/章节/难度/祝福/遗物
```

**状态机**：`MENU → WORLD → BOOT(遗物) → BUILD ⇄ WAVE → DRAFT → … → OVER`，另有 `SHOP / CODEX / SETTINGS / HELP` 弹层。

## 3. 数值模型（核心公式）

### 3.1 暴露时间与 DPS 预算

- 瓦片边长 `TILE=48`，画布 960×576（20×12 格）。
- **路径长度**（实测，单位：格）：

| 地图 | 长度 |
|---|---|
| map_1 星光平原 | 44.0 |
| map_2 赤焰火山 | 42.0 |
| map_3 冰晶湖畔 | **80.0**（最长，考验经济） |
| map_4 雷霆峡谷 | 50.0 |
| map_5 迷雾丛林 | 48.0 |

- **暴露时间** `T_exp = 路径长度 / 敌人速度(格/秒)`。例：小怪 0.8 格/s → ch1 约 55s，ch3 约 100s。
- **波次 DPS 需求**：`DPS_needed ≈ 波次总HP / (T_exp × 0.6)`（取 60% 暴露时间作为有效输出窗口，因为怪物进塔范围有先后、塔位非全覆盖）。
- 该预算用于**关卡设计验证**，不是运行时计算。

### 3.2 波次成长曲线（导演公式）

```
countScale   = 1 + 0.18 × (wave-1)
hpScale      = (1 + 0.24 × (wave-1)) × chapterScale
chapterScale = 1 + 0.16 × 章节序号0起   // ch1=1.00 ch2=1.16 … ch5=1.64
speedScale   = 1 + 0.02 × (wave-1)
难度(多=星尘倍率 hp=敌人HP 速=敌人速度 退=出售退款 收=局内金币):
  甜梦  多1.00 HP×1.00 速1.00 退0.70 收1.00
  心动  多1.40 HP×1.35 速1.05 退0.60 收1.10
  心颤  多1.90 HP×1.85 速1.12 退0.50 收1.10
精英墙/Boss墙: 心动/心颤难度下精英怪HP +22%/+44%、Boss HP +20%/+40%（难度差异化压力点）
```

> 相比 v2：count 0.16→0.18、hp 0.22→0.24，配合更强构筑池；Boss 波单独公式（见 §7）。
> **重要修正在 v2 就存在的缺陷**：难度 HP 倍率此前从未实际作用于敌人（只乘了金币），导致高难度反而更好打——v3 已修正并在 §12 用模拟验证。

### 3.3 经济曲线

```
开局: 120🪙 / 20❤️
每波奖励: bonus = (24 + wave×3) × 波次红包倍率
击杀奖励: bounty = 敌人基础赏金 × 金币加成 × 难度收入倍率(1.0/1.1/1.1)（宝藏波 ×2）
利息(需升级牌): 每波结束 + 现有金币×6%（上限 +150）
出售退款: 70% × 难度退款系数（甜梦0.70 / 心动0.60 / 心颤0.50）
```

**经济验证表**（无利息、无加成、普通难度，纯公式推演）：

| 波 | 波奖励 | 预计击杀赏金 | 累计收入 | 建议可建塔数(均¥60) |
|---|---|---|---|---|
| 1 | 27 | ~40 | 187 | 3 |
| 3 | 33 | ~90 | ~330 | 4~5 |
| 5 | 39 | ~180 | ~560 | 7~8 |
| 7 | 45 | ~300 | ~920 | 10~11 |
| 10 | 54 | ~600 | ~1600 | 13~16 |

> 目标：普通难度第 10 波前玩家应有 **10~14 座 1-2 级塔**（含卖旧换新），噩梦约 8~12 座但更强。

## 4. 塔（5 流派 × 3 级）

### 4.1 基础数值表（Lv1）

| 塔 | 元素 | 图标 | 造价 | 伤害 | 攻速(s/发) | 射程(格) | 面板DPS | 流派核心 |
|---|---|---|---|---|---|---|---|---|
| 星塔 | 星 | ⭐ | 45 | 9 | 1.1 | 2.5 | 8.2（期望12.3，暴击25%×3.0） | 精准爆击：单体高爆发 |
| 火塔 | 火 | 🌋 | 70 | 14 | 1.0 | 2.2 | 14 + 灼烧9/s×2s | 点燃蔓延：死亡爆炸传染 |
| 冰塔 | 冰 | ❄️ | 60 | 6 | 1.1 | 3.0 | 5.5 + 减速/冻结 | 冻结碎裂：控制+溅射易伤 |
| 雷塔 | 雷 | ⚡ | 100 | 10 | 1.3 | 3.0 | 7.7 ×(1+2链) | 电弧连锁：群体+电涌+过载 |
| 木塔 | 木 | 🌿 | 85 | 4 | 1.4 | 2.8 | 2.9 + 毒5/s×2.5s + 毒雾 | 剧毒纠缠：范围DOT+缠绕 |

**升级成长**（每级）：

```
Lv2: 伤害×1.5  射程×1.10  攻速×0.90
Lv3: 伤害×1.35 射程×1.08  攻速×0.92   （合计 Lv3 ≈ 伤害×2.03）
升级费用 = 基础造价 × 级数   （星:45/90/135 … 雷:100/200/300）
满级后: 额外 +8% 攻速（毕业补偿）
```

### 4.2 流派机制明细

- **⭐ 星塔·精准爆击**：25% 概率暴击×3.0（新手唯一塔，数值偏强以保证第一章单塔流可通关）；升级牌堆暴击率/倍率；暴击金色大字+音效。无克制、无范围 = 纯单体高期望。
- **🌋 火塔·点燃蔓延**：命中附加灼烧（DPS 可叠加、持续刷新）；**被灼烧敌人死亡 → 爆炸**（范围1.3格、传染灼烧+伤害）；火系免疫岩浆地形。克制木系×1.5。
- **❄️ 冰塔·冻结碎裂**：命中减速；18% 冻结 0.9s（冰面地形×2、暴风雪+15%）；**冻结中目标再次被命中 → 冰裂溅射**（1.2格、溅射伤害0.9×、全体易伤×1.3 2s）并解除冻结。克制火系×1.5。
- **⚡ 雷塔·电弧过载**：命中后**连锁 2 个**（1.5格内）；命中处留**电涌**区域（持续伤害）；20% 概率**过载**——全屏随机 3 道电弧。雷石地形+20%、雷暴事件+20%。克制水系×1.5。
- **🌿 木塔·剧毒纠缠**：命中处生成**毒雾**（1.2格、毒5/s、缠绕减速0.7）；目标直接中毒；**中毒死亡留下毒池**；毒沼地形范围+50%。克制雷系×1.5。

### 4.3 元素克制与反应

```
克制: 攻击元素 == 敌人弱点 → 伤害×1.5（弱点提示: 敌人右上角色块）
反应:
  火+木 = 燃爆    燃烧中的敌人受毒伤×2
  冰+雷 = 破甲    冻结目标被雷击 → 易伤×1.3 (2s) 并解除冻结
  冰+火 = 蒸发    冻结目标被火击 → 伤害×1.5 并解除冻结
  雷+水 = 导电    雷击水元素敌人 → 连锁数+1
```

### 9.1 星尘结算公式

```
stardust = floor(wave×3 + bosses×10 + 剩余HP×2 + 首通章节奖励+80) × 难度倍率，最低 5
```
