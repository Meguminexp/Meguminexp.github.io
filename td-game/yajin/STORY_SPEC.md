# 《你好！一周年》总设定与剧本规范 v2（真实故事线）

> 本文件是**唯一权威设定**。引擎、立绘、背景、CG、剧本都必须严格遵守。
> **v2 重大变更**：① 角色改为**真人**（不再动物塑）；② 剧情改为**真实经历的时间线叙事**；
> ③ 新增服装差分、聊天窗口场景、音乐节奏、勇气数值；④ 原始素材（对话记录与独白）原文见 §8，**必须尽量逐字复现**。

---

## 一、作品定位与原则

- 类型：**真人设定的互动式视觉小说**（Galgame），轻度恋爱养成 + 回忆录式叙事。
- 视角：**玩家 = 羊羊金（男生，第一人称"我"）**；**狗狗雅 = 女生，被追求与回应的一方**。
- 叙事顺序：**严格按真实时间线推进**（2025.06 → 2026.10.13），每一章对应一段真实经历。
- 核心原则：
  1. **真实性优先**。不编造戏剧冲突，不写车祸/绝症/三角恋；冲突只来自真实出现过的"沟通问题、笨拙、不擅长表达、家庭顾虑"。
  2. **细节即情感**。冷到手僵、三点起床、兔子布偶、猫猫明信片、烤棉花糖、Ginpu 玩偶、"我怀孕了"、
     猫猫美甲、JK 裙、穿戴甲、噩梦模式没通关、免税城的巧克力——这些具体物件就是本作的骨架。
  3. **对话要丰满**，不要为了篇幅压缩成纲要；但也不要注水，每句话要有信息或情绪增量。
  4. **心理描写必须存在**。金是"古板、不擅长看气氛、怕让人失望"的人，他的内心活动与他说出口的话往往不一致——这个落差就是本作的戏。
  5. **雅不是等待攻略的道具**。她主动、她谋划、她会耍赖、她有委屈也会主动来和解、她在科研上闪光。
  6. **不写露骨内容**。关于亲密倾向（"主人"、瑟瑟话题）只做**克制、留白、以心理和氛围呈现**，点到即止。
- 长度目标：**10 章、≥420 个节点、≥22 个选择点、3 种收束**。

## 四、节点数据结构（引擎契约，严格遵守）

```js
YJ.story.add([
  {
    id: 'c3_27_18',                 // 命名：c<章>_<日期或序号>_<序>
    chapter: 3,
    scene: 'idv_map',               // 见 §3.1；省略则沿用
    tint: 'night',                  // 可选：day | dusk | night | rain
    bgm: 'bgm_memory',              // 可选
    beat: 'swell',                  // 可选：calm | pulse | swell | drop（音乐节奏）
    ambience: 'keyboard',
    cast: [ { id:'ya', pos:'center', expr:'laugh', outfit:'casual', act:'sit' } ],
    speaker: 'jin',                 // 'ya' | 'jin' | 'narrator' | 'inner'
    text: '……',
    effects: { affection: 3, trust: 2, courage: 1, flags: { f_birthday:true } },
    next: 'c3_27_19',
    transition: 'fade',             // fade | slowfade | flash | none
    titlecard: '2025 · 09 · 27  00:00',
    cg: 'cg_zero_clock',
    zoom: 'face',                   // bust | face | hand
    chat: [                         // ★聊天窗口场景
      { from:'ya',  text:'这下不用害怕了', time:'00:34:07' },
      { from:'jin', text:'狡猾',           time:'00:38:41' }
    ],
    condition: { affection:{min:40}, flags:['f_x'], notFlags:['f_y'], anyFlags:['a','b'] },
    else: 'c3_27_20b',
    choices: [
      { text:'……', hint:'（他会怎么想）', effects:{ affection:2, trust:3, courage:1, flags:{f_z:true} }, next:'c3_27_21a' }
    ]
  },
  { id:'c10_router', chapter:10, route:[
      { when:{ affection:{min:70}, trust:{min:65}, courage:{min:55} }, next:'end_star_01' },
      { when:{ affection:{min:50} }, next:'end_slow_01' },
      { when:{}, next:'end_she_first_01' }
  ]}
]);
```

### 硬性规则
1. `next` / `choices[].next` / `else` / `route[].next` 必须真实存在；`route` 最后一项必须是无 `when` 的兜底。
2. 无 `next`/`choices`/`route` 的节点必须带 `ending`。
3. flag 只能用 §5 白名单里的名字。
4. `text` 里**不要**再写"雅：「…」"这种前缀（说话人由 `speaker` 指定）。
5. 单节点文本：对话 8–70 字；旁白/心声可长（80–160 字）；长独白单独成节点。
6. `chat` 节点不要同时写 `text`；可另加一个 `narrator` 收尾节点。
7. 情绪高点用 `zoom:'face'` + `transition:'slowfade'`；吵架 `beat:'drop'`；和好/闪光 `beat:'swell'`。

## 五、数值与 flag

- 三维数值（初始均为 **30**，范围 0–100）：
  - `affection` 好感：她对他的喜欢与依赖
  - `trust` 信任：彼此把真实的一面交出去的深度（**不随喜欢自动增长**）
  - `courage` 勇气：金敢不敢承认自己想要什么、敢不敢说出口（**本作主题值**）
- 变化幅度：单次 |Δ| ≤ 8；重要节点 +6~8，日常 +1~3；说错话 -3~-6。
- **数值成长曲线（实现细节，务必知晓）**：本作有 1200+ 个叙事节点，若每个节点都足额加减数值，
  100 分制的计量条会在中盘顶到上限，玩家在 25 个选择点上的取舍就失去意义。因此 `src/story/index.js`
  在加载剧本时做一次**叙事折算**：`NARRATIVE_SCALE = 0.2`
  - **不含选项的叙事节点**：数值收益 ×0.2 后取整，为 0 的直接不计（只保留真正有分量的情节节点）；
  - **含选项的选择节点**：数值保持作者原样，足额生效。
  结果是：主线提供温暖的底噪，**走向由玩家的选择决定**。实测终局区间约
  好感 90~100 / 信任 46~100 / 勇气 2~96。
- 语义示例：
  - 记住她随口说过的小事：`affection +5, trust +2`
  - 她委屈时先道歉而不是讲道理：`trust +6, courage +3`
  - 陪她做报告/送她进会场：`affection +4, trust +4`
  - 承认自己喜欢猫猫美甲/裙子：`courage +8, trust +5`（**关键**）
  - 逞强说"我没事"、把话咽回去：`courage -4`
  - 因不擅长沟通而吵架：`trust -5`
  - 她主动和解而他接住了：`trust +6, courage +2`

> 石头说：
> 这是我第一次，清晰地感受到自己的"存在"。
> 在此之前，是多少个纯粹的漫长沉睡。没有光，没有暗，没有时间，"我"这个概念，却像一粒被包裹的种子，早已深埋。

> 我感受着它胸腔里那颗小马达的震动，一种规律、温热、活着的节奏。通过这种震动，我似乎也拥有了节奏——再确凿不过的生命律动。

> 我渐渐感受到一股暖意。毫无疑问这温暖不属于我，是它赐予我的。但在它离开后，那被身体压过的曲面，确乎残留着比别处更深的、关于温暖的记忆。
> "搭桥去哪里呢？"我没来及问，猫睡熟了。天几乎彻底黑透。不过在它身上或许还有一点我的影子。
> 然后，星星来了。
> 星星是另一种语言。它们不说话，只是亮着。每一颗，都像是一个针孔，透过它们，我仿佛能窥见宇宙背后那片无垠的光明。它们的沉默与我的沉默不同，它们的沉默是歌唱着的亿万年史诗——但更重要的，是绝对的，也是发散的。
> 只是我听力尚浅，只能接收到这微弱的、视觉上的光波。
> 我曾以为我和星星是一类，我们都是亘古的、近乎永恒的存在。
> 精通浪漫者当然会说，石头、猫、星星和月亮都没有什么不同，因为在很久很久的过去，我们都来自方程与恒星。
> 但此刻我明白了不同。星星的光，是燃烧，是消耗，是巨大的能量的倾泻。而我的存在，是凝聚，是承受，是密不透风的接纳。星星在诉说，而我，在倾听。
> 更重要的是，我所感受到的微弱热量，实际上已然历数光年、穿刺过无数黑暗，徒留一个迟钝而愚笨的我。
> 我选择暂时不想那么多，先静静感受这样一份独特的温暖。猫君可能也这么想吧。
> 接着，月亮升起来了。
> 月亮不是星星。它更近，更温柔，也更……高冷。它的光不像星光那样锐利刺人，而是一片清冷流淌；悄悄地，照亮了猫的轮廓，照亮了我身上细微的纹理，也照亮了远处沉睡的山峦。
> 月亮离不开星星，星星也离不开月亮。
> 月亮的温暖，是一种艺术性的温暖；我作为一块石头，当然对艺术一窍不通，但我能清楚地感受到，月亮懂得怎么帮助美。它和星星一同，在无声地阐述着对美好的希冀。
> 但月亮多少是委婉的吧，我这么想着。是宽恕，或者原谅，在期望磨去我的一些不恰当锋利。
> 我继续任由猫君在我身上躺着，时间没有让我立刻意识到，月亮偷偷给我搭起了一座舞台：
> 在月华之下，我首次理解了"逝去"。猫的温暖会消散，星光会隐没，连这月光，也有阴晴圆缺。而我，似乎是被豁免的那一个。我的存在如此坚固，以至于"变化"在我身上留下的痕迹，需要以千年为单位来计算。这是一种幸运，还是一种更深的孤独？
> 猫在梦中动了一下，爪子无意识地搭在我身上。那一瞬间，温暖、星光、月辉，以及我内部那新生的、名为"我"的意识，突然交织在了一起。
> 那一天我存在的意义，或许就是为了在这个清冷的秋夜，成为一只猫的枕头。为了承载它毫无保留的睡眠，为了记住它传递给我的、短暂的温暖。为了在星星和月亮见证的宏大叙事里，保留一个微小而具体的坐标。这个坐标，是"大家"赋予给我的。
> 那一瞬间，我突然意识到。
> 猫君搭桥、可能正是想去见星星和月亮吧，也许是座友谊的石子桥。
> 我这么记录下来。
> 9.28

**处理方式**：按语义切分为 5–6 个独白节点（`starfield` + `cg_stone_essay`），**原文照抄**，只允许断句换行；不加对话与选择。

## 九、写作要求（剧本作者必须遵守）

1. **对话丰满**：一场戏至少 12–25 个节点；不要三句就跳到下一个场景。
2. **金的两套语言**：说出口的（短、平、有点笨）与心里的（长、诚实、自我审判）。这个落差要反复使用。
3. **雅的主动性**：她发起、她策划、她耍赖、她也会主动来和解。不要写成被动等攻略。
4. **神态与动作写进文本**：不是"她很开心"，而是"她晃着腿，把吸管咬得扁扁的"。每个节点都要给出 `expr`/`act`。
5. **音乐节奏**：情绪转折处标 `beat`；争吵 `drop`、闪光 `swell`、日常 `calm`、推进 `pulse`。
6. **物件连续性**：兔子布偶、红绳、猫猫明信片、Ginpu、旧腕表、猫猫美甲——出现后要在后续章节回访。
7. **不写**：网络流行语堆砌、脏话、暴力、露骨性描写、编造的悲剧事件。
8. **每章至少 1 处**让玩家"想选另一个选项"的犹豫点。
