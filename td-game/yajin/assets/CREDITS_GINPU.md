## 二、Ginpu 的角色设定（这张 CG 画的就是它）

Ginpu 是一只**毛绒企鹅玩偶**：圆滚滚、短短的翅膀、看起来抱着就很软。
它的识别点全部由本作自己定，逐条落实在 `tools/build-ginpu-cg.js` 里：

| # | 设定点 | 具体做法 |
|---|---|---|
| 1 | **深蓝灰身体** | 身体 `#3B4A63`、暗部 `#26314A`、小翅膀亮一档 `#5A6E93`、左上轮廓光 `#8A9CBB`。**不是「黑身白肚」那一套**：头部整块深蓝灰，白色只属于肚皮 |
| 2 | **短小的金黄小尖喙** | 宽 44（约头宽的 3 成）、高 55，圆顶向下收成小尖，落在两眼之间偏下，距下巴线还留一段；喙缝一条、左上一点高光 |
| 3 | **小眼睛 + 腮红** | 白眼球半径 10.4（约头宽的 1/14），瞳孔更小，各带两点高光；两颊两块 `#E9838F` 腮红。**刻意不做占满半张脸的大白眼** |
| 4 | **三根呆毛** | 头顶三根短羽，深浅两层描线，让轮廓不那么「圆滚」，也是最好认的一处记号 |
| 5 | **浅蓝肚纹** | 暖白肚皮 `#F6F2E9` 正中一条竖的浅蓝纹 `#D3E5F7`，两侧配虚线绒布缝线 |
| 6 | **浅金三趾小脚掌** | `#E9B45C` 扁椭圆 + 三个趾头，带趾缝与顶部高光。**不用橙红大脚掌** |
| 7 | **配饰** | 红围巾 `#C0574E`、苔绿针织帽 `#6F8F5E`（奶白帽檐与绒球）、小银鱼 `#9FB3C2`——对应剧情写的「围巾的、洗澡的、抱鱼的、戴帽子的」 |

画面语言向本作其它手绘 SVG 靠：平涂 + 分层，不让深色糊成一块；
表情做 4 种（睁眼 / 笑眼弯弯 / 惊讶睁大 / 单眼眨），玩偶堆里混着排，避免呆板。

## 三、与常见企鹅角色刻意的区别

为了确保它是**另一个角色**，而不是「换个名字的同款仿画」，下面这几条是**反着做的**：

| 常见企鹅角色的标志 | Ginpu 的做法 |
|---|---|
| 又大又宽、向下垂的橙红色喙（宽约达头宽 2/3，喙尖低于下巴） | 短小的金黄小尖喙（宽约头宽 3 成，喙尖远在下巴线以上） |
| 黑色身体 + 白色一路延伸到脸的下半，连成「黑头罩 + 白脸下缘 + 白肚皮」 | 深蓝灰身体，**头部整块深色**，没有白脸下缘，白色只属于肚皮 |
| 一对占掉大半张脸的大白眼 + 大量白高光 | 小眼睛 + 腮红，白眼球只有头宽的 1/14 |
| 橙红三趾大脚掌 | 浅金三趾小脚掌 |
| —— | 另外加上**呆毛**与**浅蓝肚纹**两处只属于 Ginpu 的记号 |

## 四、画面本身（`assets/cg/cg_ginpu.svg`）

| 项目 | 内容 |
|---|---|
| 画布 | **1600×900**（与其它 CG 一致） |
| 体量 | 约 **31 KB**，**20 只** Ginpu 玩偶（16 只正面 + 4 只背面），纯手写 SVG，**零位图 / 零 base64 / 零外部引用** |
| 构图 | 「玩偶堆成小山」：3 排由远及近叠起（第 1 排 5 只 → 第 2 排 7 只 → 第 3 排 6 只）＋ 左右各 1 只倾倒溢出的，共 20 只（其中 4 只画成背面款增加层次）。后两排露出约 6 成头部，所以看过去是**一座小山**而不是**一排墙** |
| 呼应剧情的细节 | 剧情写「围巾的、洗澡的、抱鱼的、戴帽子的」——画面里对应给了**红围巾 / 苔绿针织帽 / 小银鱼**三种配饰，散布在不同玩偶上 |
| 画风统一 | 房间沿用 `assets/backgrounds/hotel.svg` 的同一套色（暖紫墙 `#2A2434`→`#171420`、夜窗 `#1B2A44`→`#0E1726`、床头灯暖光 `#F5CE7E`、床品 `#4A3E50`→`#241E2C`），并加暗角 + 顶部压暗，避免和立绘合成 CG 打架 |
| 安全区 | 游戏内对话框遮挡 y ≈ 622–866（`index.html` `#dialog`：`bottom:34u`、高约 `244u`）。玩偶堆整体控制在该线以上，脚掌踩在 y ≈ 620 |

### 复现 / 重新生成

```bash
node tools/build-ginpu-cg.js               # 只重写 assets/cg/cg_ginpu.svg（+ 对照图）
node tools/build-ginpu-cg.js --sheet-only  # 只出对照图
```

> ⚠️ **不要**改用 `node tools/build-cg.js`：那个脚本会一次性重建全部 17 张合成 CG，
> 会覆盖其它 CG（含 `cg_nail_art` / `cg_end_*`）。本 CG 是手绘型，不在 `build-cg.js` 的范围内。

### 本项目内的自检文件

- `assets/ginpu/doll_reference.svg` — 同一套矢量部件的放大对照图（整只 2.6×、脸部 3.6×、表情与配饰差分）。
- `assets/ginpu/preview.html` — 1:1 显示 `cg_ginpu.svg`，并画出对话框遮挡区虚线框。

## 五、诚实的局限

1. **这是平涂矢量，不是毛绒实拍**：没有绒毛反射、没有布料纹理，也不做黏土质感。
   它的目标是「一眼看出是一只原创的可爱企鹅玩偶」，而不是仿真玩偶照片。
2. **画风落差是本来就有的**：本作角色立绘是外部 CC0 位图（半写实日系），本 CG 是平涂矢量。
   本 CG 属于「纯手写 SVG」那一类（与 `cg_forum` / `cg_birthday_map` / `cg_chat_confess` /
   `cg_stone_essay` 同类），和「背景＋位图立绘合成」的另外 16 张本来就不是一路。
3. **只能是「原创且通用」**：企鹅本身的通行造型（圆身、白肚、短翅）属于自然形象的公共部分，
   本作不主张对这些通行特征的权利；主张的是上面第二节那 7 条**具体设定**
   （配色、短小金黄喙、小眼睛 + 腮红、呆毛、浅蓝肚纹、浅金小脚掌、配饰组合）。
4. **没有任何第三方素材需要署名**，所以 README 的「素材来源与许可」一节里，
   这张 CG 归入「本作自绘矢量」一类。
